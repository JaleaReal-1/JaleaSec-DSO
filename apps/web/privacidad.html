Solicitudes comerciales

El formulario prepara un mensaje en tu navegador con los datos que escribes. JaleaSec no almacena el formulario en una base de datos ni lo envía automáticamente. Solo lo compartes cuando abres WhatsApp y envías el mensaje.

Usaremos lo que compartas para evaluar y responder tu solicitud, elaborar una propuesta y coordinar contigo. Evita enviar contraseñas, información médica, documentos privados o datos de otras personas.

WhatsApp y datos de contacto

Al enviar el mensaje utilizas un servicio externo y sus condiciones de privacidad. Puedes solicitar por el mismo chat que dejemos de contactarte o eliminemos los mensajes que estén bajo nuestro control. Contactar a JaleaSec.

Demo y aplicación local

Campus Planner guarda cursos, tareas y notas en el dispositivo: almacenamiento del navegador en la demo, y almacenamiento nativo en Android. No se envían a una API y no se sincronizan. Los ejemplos incluidos son ficticios.

Las copias JSON son archivos legibles, sin cifrado. Guárdalas en un lugar privado. Borrar el almacenamiento, desinstalar la app o perder el dispositivo sin copia puede hacer que pierdas los datos. La demo permite borrar todos sus registros desde Ajustes.

Infraestructura

Esta web no usa analítica ni cookies publicitarias. El servidor web puede registrar datos técnicos de acceso, como IP, ruta y hora, para operar el sitio. No existe una cuenta comercial, pago ni panel de clientes.

Alcance

Esta política describe la web pública y su demo. Cada entrega a un cliente debe definir por separado el acceso, la conservación, los respaldos y cualquier servicio adicional que use datos personales.
